# Build PTag Admin APK

Upload the contents of this project folder to the root of a GitHub repository. The included GitHub Actions workflow builds a debug APK on pushes to `main`/`master` or by manual dispatch.

Download the `PTag-Admin-APK` artifact from the workflow run. The artifact contains `app-debug.apk`.

App ID: `com.ptag.admin`
App name: `PTag Admin`
Backend: `https://anpr-api.gconnectt.com`
